# Getting help

| You want to | Go to |
|---|---|
| Learn how to start | [Getting started](README.md#all-the-guides) |
| Connect it to your app | [Connect your agent](docs/connect-your-agent.md) |
| Report a bug | [Something doesn't work](https://github.com/Phygital-Key/phygital-key-a2a/issues/new?template=bug_report.yml) |
| Ask a question | [Question](https://github.com/Phygital-Key/phygital-key-a2a/issues/new?template=question.yml) |
| Share an idea | [Idea or feature](https://github.com/Phygital-Key/phygital-key-a2a/issues/new?template=feature_request.yml) |
| Report a security problem, privately | [Private report](https://github.com/Phygital-Key/phygital-key-a2a/security/advisories/new) ([SECURITY.md](SECURITY.md)) |

Issues are public. Leave out passwords, keys, tokens and private data. This is a project run in spare time, so answers can take a few days.
